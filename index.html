Breadth-First Search (BFS)

Uses a FIFO Queue. Traverses node-by-node layer by layer. Guarantees finding the path with the minimum number of edge hops (optimal for unweighted graphs).

Depth-First Search (DFS)

Uses a LIFO Stack. Dives deeply along each branch until a dead-end before backtracking. Fast and memory-lean on deep graphs, but rarely yields optimal paths.

A* Search (A-Star)

Uses a Priority Queue evaluated by f(n) = g(n) + h(n). Combines past cost g(n) with heuristic estimate h(n) to guarantee finding the optimal lowest-cost path with minimal node expansions.
